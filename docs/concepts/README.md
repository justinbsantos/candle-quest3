# Character & home concepts (TBA)

The final character and room are not decided yet. These are the concepts on the table.

- `animal-crew.png`: the leading character direction, with 8 animals and 7 preset looks.
- `room-progression.png`: the leading room direction. It starts in a tiny run-down room and upgrades through Bedroom and Studio apartment.
- `board/`: source for every concept screen on the Claude design board ("Wickd for Everyone — Concepts"). These files run inside that board's editor, not on their own. They hold all the item lists, colors, prices and drawing code to port into the game.

| File | What it is |
|---|---|
| `Animals.dc.html` | Animal crew creator: animal, fur, eyes, mouth, top, bottom, head, Cute/Cool/Both vibe, emotes, presets |
| `Wickling.dc.html` | Wicklings: squishy party-game characters with a candle flame (earlier direction) |
| `CreatorV2.dc.html` | Soft 3D human trader (the version currently built into the game) |
| `Main.dc.html` | First flat character creator concept |
| `RoomV3.dc.html` | Diorama room: tiny room → bedroom → studio, upgrades with perks, themes |
| `RoomV2.dc.html` | First isometric trading setup concept |
| `RoomStyles.dc.html` | Room style picker (Cozy, Gamer, Clean, Street) |
| `Lifestyle.dc.html` | Homes and garage that unlock with Pro Account milestones |
| `Rewards.dc.html` | Dream board, pets, trader card, friend visits |
| `Themes.dc.html` | Soft pastel theme for the home screen |
| `League.dc.html` | League screen with mixed rival names and coach voice |
